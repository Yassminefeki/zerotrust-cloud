# Security

This document summarises the security controls per layer and where each is proven. The attacker
model, the attack catalogue and the residual risks are in [THREAT-MODEL.md](THREAT-MODEL.md).

## Controls

| Layer | Control | Implemented in | Proven by |
|---|---|---|---|
| Network | default-drop nftables on every VM, silent and logged denials | [`tools/gen_rules.py`](../tools/gen_rules.py), [`ansible/roles/nftables/`](../ansible/roles/nftables/) | [`tests/firewall/`](../tests/firewall/), [evidence/drift-summary.md](evidence/drift-summary.md) |
| Network | only the gateway routes; tunnel → frontend:8443 only | gateway ruleset | [`tests/wireguard/`](../tests/wireguard/) |
| Network | host DNAT by interface name, no Wi-Fi address anywhere | [`ansible/roles/host/`](../ansible/roles/host/) | [`tests/host/`](../tests/host/), [`tests/unit/test_policy.py`](../tests/unit/test_policy.py) |
| Transport | WireGuard with per-peer PSK; cryptokey routing | [`ansible/roles/wireguard/`](../ansible/roles/wireguard/) | [`tests/wireguard/`](../tests/wireguard/) |
| Transport | TLS 1.3 only on every hop, PostgreSQL included | [`zt-mtls`](../ansible/roles/app/files/zt-mtls), [`ansible/roles/postgres/`](../ansible/roles/postgres/) | [`tests/final/test_confidentiality.py`](../tests/final/test_confidentiality.py) |
| Identity | 24 h SPIFFE certificates, keys generated where used | [`ansible/roles/ca/`](../ansible/roles/ca/), [`ansible/roles/pki-client/`](../ansible/roles/pki-client/), [`ansible/certs.yml`](../ansible/certs.yml) | [`tests/ca/`](../tests/ca/), [`tests/pki/`](../tests/pki/) |
| Identity | CA issuance policy (names, URIs, IPs, lifetime) | generated `build/pki/pki.json` | [`tests/ca/`](../tests/ca/) |
| Identity | revocation, fail-closed, no restart | [`zt-crl`](../ansible/roles/app/files/zt-crl), [`ansible/revoke.yml`](../ansible/revoke.yml) | [`tests/unit/test_revocation.py`](../tests/unit/test_revocation.py), A1 |
| Authorization | per-service allow-list + source address; per-role routes; device binding | generated `mtls.json` | [`tests/actors/`](../tests/actors/), [`tests/edge/`](../tests/edge/) |
| Application | CSRF (JSON-only, same-origin), CSP, text-only rendering, idempotency keys | [`zt_bank.py`](../ansible/roles/app/files/zt_bank.py), [`www/`](../ansible/roles/app/files/www/) | [`tests/web/`](../tests/web/), [`tests/unit/test_web_ui.py`](../tests/unit/test_web_ui.py) |
| Application | signed, time-boxed, single-use partner webhook | frontend `partner` app, `bank.incoming_payment()` | [`tests/unit/test_partner.py`](../tests/unit/test_partner.py), [`tests/edge/`](../tests/edge/) |
| Data | RLS, no write grants, append-only ledger, audit with SPIFFE identity | [`bank.sql.j2`](../ansible/roles/postgres/templates/bank.sql.j2) | [`tests/bank/`](../tests/bank/) |
| Availability | per-identity rate limit, per-peer connection limit | `zt-mtls`, gateway ruleset | [`tests/edge/`](../tests/edge/) |
| Secrets | generated by Ansible outside Git, `no_log`, never printed by tests or tools | [`.gitignore`](../.gitignore), [`ansible/`](../ansible/) | [`tests/unit/test_no_personal_data.py`](../tests/unit/test_no_personal_data.py) |
| Detection | every refusal logged with the real identity; `make audit` | [`tools/zt-audit.py`](../tools/zt-audit.py) | [evidence/audit.md](evidence/audit.md) |

## Secrets inventory

| Secret | Location | Created by |
|---|---|---|
| CA key and provisioner passwords | `ansible/.secrets/`, `/etc/step-ca/secrets/` | `make ca` |
| WireGuard private keys and PSKs | `ansible/.secrets/wireguard/`, `/etc/wireguard/` | `make wireguard` |
| actor keys, Firefox bundles and their passwords | `ansible/.secrets/pki/<cn>/` | `make client-certs` |
| VM keys | `/etc/zt/pki/cert.key` on each VM | `make certs` |
| partner HMAC secret | `ansible/.secrets/partners/`, `/etc/zt/partners/` | `make services` |

None of these is tracked by Git ([`.gitignore`](../.gitignore)); see also
[21-secrets-et-donnees-personnelles.md](21-secrets-et-donnees-personnelles.md) (FR) for the pre-publication checklist.
